Generate an image

Runs on the server and typically takes 60–120 s — that is the engine rendering, not a hang. One generation at a time; a 429 just means wait. Watermarks are removed before the image is served. You can reload or close this page — the job keeps running and the result shows up under Recent.

Recent

Newest first — everything that has finished, including jobs started in another tab or before a reload.

Upload a reference image

Sends the image into the project's Uploads as a prompt ingredient (maseQ, bytes inline as base64). Max 4 MB. Honest scope: the upload is wired — using an uploaded image as the input to a generation is not, because that request shape is still unmapped.

Notes

• Passing an API key: programs send Authorization: Bearer <key>; this page also uses ?key= so images render in a browser.
• Upload / reference images: POST /upload is live (maseQ, inline base64). The upload works; feeding an uploaded image into a generation is still unmapped.
• Google's sparkle watermark is stripped server-side at generation time.
• Free tier: one generation at a time, and the service sleeps only if /health stops being polled.
